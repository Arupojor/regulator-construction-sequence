Eleven stages of regulator construction, from planning to trial operation.
I created Python code and an HTML file to create an animation video of the construction sequence of a regulator, a common hydraulic structure in Bangladesh's coastal region. The animation video describes the construction sequence in detail, following the design. It shows a coastal drainage and irrigation regulator in four views—longitudinal section, plan from above, and elevations from both the river and countryside—with the two gates operating through a tide cycle at the end.
The aim was to show what a finished structure hides: the cut-off wall, the piles, the pile heads cast into the RCC base, the chute and baffle blocks in the stilling basin, and the distinguishable differences between the downstream and upstream floors.
Geometry follows BWDB standard drawings. 
Hope this is useful for your learning or teaching purposes.
